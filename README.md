## 1. Nombre del proyecto
Proyecto Educacional (Microservicio Spring Boot)

## 2. Integrantes

## 3. Funcionalidades
- Microservicio REST en Spring Boot conectado a MySQL.
- Operaciones CRUD iniciales (`/api/registros`: GET, POST, PUT).

## 4. Endpoints utilizados (API externa y microservicio)
- Microservicio propio: `http://localhost:8080/api/registros`
- API externa: Pendiente de integrar en app móvil.

## 5. Pasos para ejecutar
1. Iniciar MySQL en XAMPP (puerto 3306).
2. Ejecutar `EducacionalApplication` en IntelliJ IDEA 2026.2.1.
